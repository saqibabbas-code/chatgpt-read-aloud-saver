ChatGPT Read Aloud Saver

For Chromium-based desktop browsers · by saqibabbas-code

Designed for Chrome, Edge, Brave and compatible Chromium desktop browsers. Firefox and Safari are not supported by this package; live browser compatibility testing remains required.

Keep ChatGPT’s spoken responses as audio files you can play later or copy to your phone.

Install once

  1. Extract the downloaded ZIP.Right-click it in File Explorer → Extract All. Keep the extracted files in a permanent folder.
  2. Open your browser’s extensions page.Chrome: chrome://extensions
    Edge: edge://extensions
    Brave: brave://extensions
    For other Chromium browsers, open their extensions manager.
  3. Turn on Developer mode.Find the switch on the extensions page, then choose Load unpacked.
  4. Select chatgpt-read-aloud-saver.Choose the inner folder directly containing manifest.json, then click Select Folder.
  5. Refresh your ChatGPT tab.The extension begins observing new audio after the page reloads. You can pin it from your browser’s extensions menu.

Choose a format → Save audio

Use ChatGPT’s Read Aloud control on a response. When its audio file has fully loaded, a new player appears at the bottom right of the page.

MP3WAVOriginal audio

Choose MP3 for an easy-to-share file. Choose Original audio to keep the supplied file unchanged. Find your saved file in your browser’s Downloads.

For 7–8-minute responses: the tool allows up to 15 minutes for loading. An eight-minute MP3 at 128 kbps is about 7.7 MB. Keep the ChatGPT tab open until you save.

Which folder should I select?

Select the extracted chatgpt-read-aloud-saver folder. This is the folder directly containing manifest.json. Keep it in a permanent location so your browser can load the extension.

chatgpt-read-aloud-saver/manifest.json
If the player does not appear

Refresh ChatGPT after installing, then try Read Aloud on a short response. Previously played audio may be cached. Open the extension popup to check status. If conversion fails, try Original audio. Captured clips clear when you refresh or close the tab.

This version observes supported audio responses sent through page requests. Changes in ChatGPT’s audio delivery can prevent capture. Live signed-in ChatGPT testing in each target browser is still needed.

See the full instructions for limits, privacy, and troubleshooting.

No API key or microphone required. Audio conversion stays on your computer. This version uses the voice supplied by ChatGPT and supports individual responses. It has no separate voice selector or bulk export. Desktop use only; saved files can be transferred to your phone.
